# 參考作品分析：《沙羅曼蛇》（Konami，1986，街機）

本文件拆解原作的機制，並決定每一項在本專案中「保留、修改或捨棄」。它是 `GDD.md` 的設計依據。

> 以下內容憑記憶整理，未逐項對照原作驗證。標註「需確認」的項目，動工前請對照原作遊玩影片再確認一次。

## 1. 原作的核心特徵

| # | 特徵 | 原作的做法 | 帶來的體驗 |
|---|---|---|---|
| 1 | 橫縱交替 | 共 6 關，奇數關橫向捲動、偶數關縱向捲動 | 節奏變化大，每關視角都新鮮 |
| 2 | 即時強化 | 吃到道具立刻生效（日版街機）。不像 Gradius 要累積能量槽再選擇 | 上手快、節奏快，不必分心管理選單 |
| 3 | 原地復活 | 中彈後在原地重生，不退回檢查點 | 不中斷節奏，適合雙人，也讓接關有意義 |
| 4 | 僚機可撿回 | 死亡時僚機散落在畫面上，短時間內可以撿回 | 死亡後不至於完全歸零，降低連鎖崩盤 |
| 5 | 雙人同時遊玩 | 1P 與 2P 同場，各自獨立強化 | 合作與搶道具的張力 |
| 6 | 有機生物關卡 | 第 1 關是生物體內部：會再生的細胞壁、伸出的觸手、咬合的尖牙 | 地形本身就是敵人 |
| 7 | 地形即死 | 碰到地形或敵人都立即死亡 | 走位精度是主要技巧 |
| 8 | 武器互斥 | 兩種主武器（波紋型、貫穿型）只能擇一，後吃的覆蓋前者 | 道具取捨：有時要刻意閃開道具 |
| 9 | 雙向飛彈 | 橫向關中飛彈同時往上下發射並沿地形前進 | 處理貼著天花板與地面的敵人 |
| 10 | 無武器升級選單 | HUD 極簡，只有分數與殘機 | 畫面乾淨 |

需確認的細節：

- 僚機上限（記憶中單人最多 4 個）
- 護盾的確切行為（可承受次數、是否只擋正面）
- 速度的段數上限
- 道具掉落規則（特定敵人固定掉落，或編隊全滅掉落）

## 2. 保留／修改／捨棄

| 特徵 | 決定 | 說明 |
|---|---|---|
| 即時強化 | **保留** | 本作的核心識別。 |
| 原地復活 | **保留** | 加上 2 秒無敵時間。 |
| 僚機可撿回 | **保留** | |
| 地形即死 | **保留** | |
| 武器互斥 | **保留** | 兩種主武器擇一。 |
| 雙向飛彈 | **保留** | |
| 有機地形機關 | **保留概念，內容原創** | 「地形會動」的設計手法保留，但具體的機關造型與配置重新設計。 |
| HUD 極簡 | **修改** | 多顯示目前的武器狀態圖示，方便現代玩家理解自己有什麼。 |
| 橫縱交替 | **延後** | MVP 只做 1 個橫向關，縱向關列入後續擴充。 |
| 雙人同時遊玩 | **延後** | 架構預留，MVP 只做單人。 |
| 畫面比例 | **修改** | 原作約 256×224（接近 4:3），本作用 384×216（16:9）。橫向視野比原作寬 50%，敵人出現到接觸玩家的時間變長，需靠提高敵彈速度或拉近生成點來補償。 |
| 繞圈（通關後難度提升重來） | **捨棄** | MVP 只有一關，沒有意義。 |
| 投幣接關 | **修改** | 改為免費無限接關，接關後分數歸零。 |

## 3. 致敬的界線

遊戲機制本身不受著作權保護，可以致敬。具體的表現形式則不能使用。

**可以做：**

- 即時強化、原地復活、僚機跟隨、雙向飛彈、武器互斥等玩法規則
- 「生物體內」這類題材方向
- 橫向捲軸射擊的類型慣例

**不可以做：**

- 使用原作或 Konami 的名稱：遊戲標題、機體名、Boss 名、關卡名
- 使用或重繪原作的精靈圖、背景、Logo
- 使用或改編原作的音樂與音效（包含語音）
- 複製原作關卡的具體配置（敵人位置、地形形狀逐格照抄）
- 做出與原作機體、Boss 外觀可辨識地相似的造型

**道具名稱的處理：** 「Speed」「Missile」「Laser」屬於通用詞。原作中僚機與波紋武器的名稱則帶有強烈的 Konami 辨識度，本作改用自己的名稱（見 `GDD.md` 第 4 章）。

## 4. 其他可參考的作品

寫關卡與調手感時值得對照：

- 《Gradius》系列：能量槽強化的對照組，關卡節奏與地形設計
- 《R-Type》：地形壓迫感與記憶型關卡設計
- 《Thunder Force IV》：武器切換與畫面演出
- 近年的獨立作品，如《Drainus》：現代化的像素演出與難度曲線
